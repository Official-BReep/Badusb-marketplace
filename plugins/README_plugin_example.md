# Marketplace-Beispiel

Ein minimales Beispielplugin, das eine Aktion zur IDE hinzufügt. Beim Auslösen wird eine kurze Meldung in der Statusleiste angezeigt.

- **Name:** Marketplace-Beispiel
- **Version:** 1.0.0
- **Abhängigkeiten:** PyQt6 und BadUSB IDE
- **Schnittstelle:** `register(ide)`; optional `unregister(ide)`

Prüfe den Quellcode, bevor du ihn aktivierst. Das Beispiel dient als Ausgangspunkt für eigene Erweiterungen.
